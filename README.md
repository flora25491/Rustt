
# 💜 RUST VISION

A standalone visual overlay interface prototype.

## Features

- INSERT — Open / Close menu
- Glow — Toggle visual effect setting
- Boxes — Toggle visual boxes setting
- Color — Choose interface color
- Simple dark interface

## Requirements

- Windows 10/11
- Python 3.10+

## Launch

Run:

python main.py

## Note

This is a standalone UI prototype.
It does not read Rust memory or detect hidden players.
